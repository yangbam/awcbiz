데이터 백업 · 발행

⚠ 실제 사이트에 반영하려면 아래 절차가 꼭 필요합니다

이 관리자 화면에서 회원사/활동이력을 수정한 내용은 이 브라우저에만 임시 저장됩니다(백엔드/DB가 없기 때문입니다). 다른 브라우저나 기기의 방문자에게도 똑같이 보이게 하려면, 아래 순서로 직접 반영해야 합니다.

  1. 아래 "회원사 데이터 내보내기" / "활동이력 데이터 내보내기" 버튼으로 members.json / activities.json 파일을 내려받습니다.
  2. 내려받은 파일로 프로젝트의 data/members.json, data/activities.json 파일을 각각 덮어씁니다.
  3. git에 커밋하고 push합니다(예: git add data/*.json && git commit -m "회원사 정보 업데이트" && git push).
  4. 배포가 끝나면 모든 방문자(다른 브라우저 포함)에게 동일하게 반영됩니다.

회원신청 내역을 포함한 이 브라우저의 전체 작업 내용을 백업/복원합니다. git 발행용이 아니라 개인 백업 목적입니다.
